# 广告思想简史项目详细评估报告

**项目名称**: 广告思想简史 (A Brief History of Advertising Thought)  
**项目类型**: 基于Streamlit的交互式教育Web应用  
**主要功能**: 广告历史教育平台 + AI聊天机器人  
**技术栈**: Python + Streamlit + Google Gemini + Azure OpenAI
